# Productivity

非代码专用的通用工作流 skills。

- **[caveman](./caveman/SKILL.md)** — 超压缩沟通模式，去掉填充语，同时保留技术准确性。
- **[grill-me](./grill-me/SKILL.md)** — 围绕计划或设计进行高强度追问，直到决策树的关键分支被澄清。
- **[handoff](./handoff/SKILL.md)** — 把当前对话压缩成交接文档，让另一个 agent 可以继续。
- **[write-a-skill](./write-a-skill/SKILL.md)** — 创建结构正确、渐进披露、可附带资源的新 skill。
